## Concepts Practiced

### For Loops

`for` loops are used when the number of iterations is known or when we need to process every item in a sequence.

Examples from this assignment:

- Number Analyzer
- Multiplication Table
- Sum and Average
- Maximum and Minimum
- Student Marks Analyzer
- Employee Salary Calculator

### While Loops

`while` loops are used when a program needs to continue running until a particular condition is met.

Examples:

- ATM Withdrawal Simulator
- Password Retry System
- Number Guessing Game
- Menu-Driven Calculator
- Shopping Cart
- Bank Account Application
- Student Registration System

### Functions

Functions are used to divide a program into reusable and manageable parts.

Examples:

- `my_sum()`
- `analyze_number()`
- Student Grade Function
- Shopping Cart functions
- Employee Salary Calculator
- Bank Account functions
- Student Registration System functions

### Nested Loops

Nested loops are used when one loop needs to run inside another loop.

Examples:

- Prime Number Finder
- Pattern Generator

## Important Learning Objective

For every program, I focused on understanding **why** a particular programming concept was selected.

For example:

- A `for` loop is useful when processing a fixed range or every item in a list.
- A `while` loop is useful for programs that should continue until the user chooses to stop.
- A function is useful when a particular piece of logic needs to be organized, reused, or separated from the main program.
- A nested loop is useful when one repeated operation depends on another repeated operation.
